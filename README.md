# Praline — Artisan créateur

Responsive one-page website for Praline, an artisan bakery, pâtisserie and café in Dakar.

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## Production

The production site is available at [praline-website.vercel.app](https://praline-website.vercel.app).

## Content source

Business information, menu items, brand direction and photography were collected from the official Instagram profile `@pralinesenegal` in June 2026. Before production launch, confirm that prices and opening hours remain current.
